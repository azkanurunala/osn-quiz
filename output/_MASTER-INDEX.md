# OSN SD Prep — MASTER INDEX 96 File

> Roadmap lengkap paket pembinaan OSN/KSN SD — **96 file × 100 soal PG = 9.600 soal**
>
> Setiap file: 100 soal Pilihan Ganda dengan pembahasan komprehensif (analisis A/B/C/D).
> Format: 100% PG · Bahasa Indonesia · Kelas 5–6 SD · Pembahasan analisis 4 opsi.

---

## Konvensi Tingkat Kesulitan

| Kode | Nama | Komposisi |
|------|------|-----------|
| `campur` | Campuran | 50 Kab + 30 Prov + 20 Nas (default OSN) |
| `mudah` | Mudah | 100% Kabupaten (KSN-K, C2–C3, 1–2 langkah) |
| `sedang` | Sedang | 100% Provinsi (KSN-P, C3–C4, 3–5 langkah) |
| `sulit` | Sulit | 100% Nasional (KSN, C4–C5, problem solving) |
| `mudah-sedang` | Mudah & Sedang | 50 Kab + 50 Prov |
| `sedang-sulit` | Sedang & Sulit | 50 Prov + 50 Nas |
