## BAGIAN I — KONSEP & STRATEGI

### 1. Apa Itu Pola Gambar?

Pola gambar adalah susunan benda (titik, kotak, korek api, batu, kursi, bunga, segi tiga, persegi) yang **bertambah secara teratur** dari gambar pertama ke gambar berikutnya. Tugas kita biasanya: **menghitung berapa banyak benda di gambar ke-n** atau **menemukan rumus polanya** lalu memakainya untuk meramal gambar yang jauh (misal gambar ke-50, ke-100).

Bedanya pola gambar dengan pola bilangan biasa: pola gambar **bisa dilihat**, jadi otak kita bisa **menghitung dulu**, lalu **mencari pola angka di balik gambar**.

### 2. Tiga Pola Klasik di OSN SD

**A. Pola Aritmetika (selisih tetap)** — paling sering muncul.
- Tiap gambar bertambah jumlah yang **sama**.
- Contoh: korek api segitiga sejajar
  - Gambar 1: 3 korek (△)
  - Gambar 2: 5 korek (△△)
  - Gambar 3: 7 korek (△△△)
  - Gambar 4: 9 korek (△△△△)
- Rumus umum: **Un = a + (n−1) × b**, dengan a = suku pertama, b = beda.
- Contoh di atas: Un = 3 + (n−1) × 2 = 2n + 1.

**B. Pola Bilangan Khusus**
- **Persegi (kuadrat):** 1, 4, 9, 16, 25, ... → Un = n²
- **Persegi panjang (rectangular):** 2, 6, 12, 20, 30, ... → Un = n × (n+1)
- **Segitiga:** 1, 3, 6, 10, 15, 21, ... → Un = n × (n+1) ÷ 2
- **Kubik:** 1, 8, 27, 64, 125, ... → Un = n³
- **Bilangan ganjil:** 1, 3, 5, 7, 9, ... → Un = 2n − 1
- **Bilangan genap:** 2, 4, 6, 8, ... → Un = 2n

**C. Pola Bertingkat / Selisih dari Selisih**
- Tiap gambar bertambah jumlah yang **bertambah** juga.
- Contoh: 1, 3, 7, 13, 21, ... selisih 2, 4, 6, 8 (naik 2 tiap kali).
- Rumus: butuh penjabaran (biasanya kuadrat).

### 4. Strategi Lima Langkah

1. **HITUNG dulu, JANGAN langsung cari rumus.** Hitung jumlah benda di gambar 1, 2, 3, 4 (atau yang ditampilkan).
2. **Tulis barisan angkanya** di kertas: misal 4, 7, 10, 13, ...
3. **Cari selisih (beda).** Kalau bedanya sama → aritmetika. Kalau bedanya naik tetap → kuadrat. Kalau bilangan persegi/segitiga → khusus.
4. **Susun rumus Un.** Periksa dengan U1, U2, U3 — kalau cocok semua, rumus benar.
5. **Hitung Un untuk n yang ditanya.** Hati-hati n besar (misal U100) — pakai rumus, JANGAN hitung satu per satu.

### 5. Trik Cepat Beberapa Pola

- **Bilangan segitiga** Tn = n(n+1)/2. Hafal: T10 = 55, T20 = 210, T50 = 1275, T100 = 5050.
- **Bilangan persegi** n². Hafal: 11² = 121, 12² = 144, 13² = 169, 15² = 225, 20² = 400, 25² = 625, 50² = 2500.
- **Korek api segitiga sejajar** = 2n + 1. **Korek api persegi sejajar** = 3n + 1.
- **Jumlah n bilangan ganjil pertama** = n² (1+3+5+...+(2n−1) = n²).
- **Jumlah n bilangan kuadrat pertama** = n(n+1)(2n+1)/6.

### 6. Anti-Jebakan Klasik

- **Salah hitung gambar 1.** Banyak siswa lupa hitung garis tengah, atau ngitung dua kali.
- **Salah identifikasi pola.** Mengira aritmetika padahal kuadrat (bedanya naik), atau sebaliknya.
- **Salah rumus.** Tn = n(n+1)/2 ≠ n²/2. n² ≠ 2n.
- **Salah substitusi n.** Soal tanya gambar ke-50, pakai n=49 atau n=51.
- **Lupa konstanta.** 3n vs 3n+1 — beda 1 saja sudah salah.

### 7. Konteks Aplikasi Nyata

- **Susunan bata piramida** — tiap baris bertambah 2 (1, 3, 5, 7, ...) → bilangan ganjil.
- **Kursi penonton stadion** — baris depan 20, tiap baris belakang bertambah 4 → 20, 24, 28, ... aritmetika.
- **Papan bunga taman** — bunga pinggir membentuk persegi → 4, 12, 20, 28, ... aritmetika beda 8.
- **Kelereng segitiga (susun seperti bola biliar)** — 1, 3, 6, 10, 15 → segitiga.
- **Kotak susun pasar** — sisi persegi makin besar → n², total dari 1+4+9+...
