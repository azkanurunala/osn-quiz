# OSN/KSN SD — MTK · Sub-Bab 02g: Pembulatan Desimal (Tingkat Campur)

> **Profil**: 50 soal Kab + 30 soal Prov + 20 soal Nas · Total **100 soal PG**
> **Fokus**: Aturan pembulatan (< 5 turun, ≥ 5 naik), pembulatan ke satuan/puluhan/ratusan/ribuan terdekat, pembulatan desimal (1 desimal, 2 desimal), pembulatan ke atas (ceiling) & ke bawah (floor), aplikasi estimasi/uang/pengukuran/jumlah kantong/jumlah orang
> **Target audiens**: SD kelas 5–6 siap OSN/KSN

## BAGIAN I · TEORI ESENSIAL

### 1. Aturan Dasar Pembulatan
Untuk membulatkan sebuah bilangan ke posisi tertentu:
1. **Lihat satu digit** yang berada **tepat di sebelah kanan** posisi pembulatan.
2. Bandingkan dengan **5**:
   - Jika digit itu **< 5** (yaitu 0, 1, 2, 3, atau 4) → bulatkan **ke bawah** (digit posisi pembulatan **tetap**, semua digit di kanannya jadi 0 atau dihapus).
   - Jika digit itu **≥ 5** (yaitu 5, 6, 7, 8, atau 9) → bulatkan **ke atas** (digit posisi pembulatan **bertambah 1**, semua digit di kanannya jadi 0 atau dihapus).

### 2. Pembulatan ke Satuan Terdekat
Lihat digit **persepuluhan** (1 angka di belakang koma).
- 3,7 → digit persepuluhan = 7 (≥ 5) → naik → **4**.
- 3,4 → digit persepuluhan = 4 (< 5) → turun → **3**.
- 12,5 → digit persepuluhan = 5 → naik → **13**.
- 8,49 → digit persepuluhan = 4 (< 5) → turun → **8** (jangan terkecoh oleh angka 9 di belakangnya — yang dicek hanya digit setelah posisi pembulatan, yaitu persepuluhan).

### 3. Pembulatan ke Puluhan Terdekat
Lihat digit **satuan**.
- 47 → satuan = 7 (≥ 5) → puluhan naik → **50**.
- 43 → satuan = 3 (< 5) → puluhan tetap → **40**.
- 85 → satuan = 5 → naik → **90**.
- 124 → satuan = 4 → turun → **120**.

### 4. Pembulatan ke Ratusan Terdekat
Lihat digit **puluhan**.
- 1.567 → puluhan = 6 (≥ 5) → ratusan naik dari 5 ke 6 → **1.600**.
- 1.534 → puluhan = 3 (< 5) → ratusan tetap → **1.500**.
- 2.450 → puluhan = 5 → naik → **2.500**.
- 749 → puluhan = 4 (< 5) → turun → **700**.

### 5. Pembulatan ke Ribuan Terdekat
Lihat digit **ratusan**.
- 1.567 → ratusan = 5 → naik → **2.000**.
- 1.499 → ratusan = 4 → turun → **1.000**.
- 8.500 → ratusan = 5 → naik → **9.000**.
- 12.349 → ratusan = 3 → turun → **12.000**.

### 6. Pembulatan Bilangan Desimal
**Ke 1 angka desimal (persepuluhan)** → lihat digit **perseratusan**.
- 3,478 → perseratusan = 7 (≥ 5) → persepuluhan naik dari 4 ke 5 → **3,5**.
- 0,743 → perseratusan = 4 (< 5) → persepuluhan tetap → **0,7**.

**Ke 2 angka desimal (perseratusan)** → lihat digit **perseribuan**.
- 3,478 → perseribuan = 8 (≥ 5) → perseratusan naik dari 7 ke 8 → **3,48**.
- 0,1234 → perseribuan = 3 (< 5) → perseratusan tetap → **0,12**.

### 7. Pembulatan ke Atas (Ceiling) vs ke Bawah (Floor)
Berbeda dengan pembulatan "ke terdekat". Pakai konteks soal!
- **Ke atas / ceiling** (selalu naik selama ada sisa): dipakai untuk **jumlah kantong, jumlah kendaraan, jumlah ruang, jumlah halaman** — kita tidak boleh "kekurangan".
  - Contoh: 73 buku, satu kardus muat 20 buku. 73 ÷ 20 = 3,65 → butuh **4 kardus** (bukan 3, karena 3 kardus = 60 buku, tidak cukup).
- **Ke bawah / floor** (selalu turun, sisa dibuang): dipakai untuk **berapa kali bisa dilakukan, berapa porsi penuh, berapa kelompok lengkap**.
  - Contoh: uang Rp 47.000, harga jajan Rp 15.000. 47.000 ÷ 15.000 = 3,13 → bisa beli **3 jajan** saja (sisa Rp 2.000 tidak cukup untuk 1 jajan lagi).

### 8. Aplikasi Pembulatan
- **Estimasi cepat**: 487 + 312 ≈ 500 + 300 = 800.
- **Pembulatan harga**: Rp 12.450 sering ditulis ≈ Rp 12.500.
- **Pengukuran**: panjang 14,7 cm ≈ 15 cm (ke satuan), atau 14,7 cm ≈ 10 cm (ke puluhan — terlalu kasar untuk pengukuran kecil).

### 9. Kesalahan yang Sering Terjadi
- **Lupa cek digit yang benar** — saat membulatkan ke ratusan, cek puluhan, bukan satuan.
- **Pembulatan berantai** — 2,449 sering salah dibulatkan jadi 2,5 (cara: 2,449 → 2,45 → 2,5). **Salah!** Lakukan **satu kali saja** langsung dari bilangan asli: 2,449 → cek perseratusan = 4 (< 5) → **2,4**.
- **Arah salah** — digit 5 sering dibulatkan ke bawah karena dianggap "tengah". Aturan SD: **5 ke atas**.
- **Floor vs ceiling tertukar** — pakai konteks: "butuh berapa kantong" = ceiling; "berapa kali bisa beli" = floor.
