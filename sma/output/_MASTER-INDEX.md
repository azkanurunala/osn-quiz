# OSN SMA Prep — MASTER INDEX 486 File

> Roadmap lengkap paket pembinaan OSN/KSN SMA — **486 file × 100 soal PG = 48.600 soal**
>
> Setiap file: 100 soal Pilihan Ganda dengan pembahasan komprehensif (analisis A/B/C/D/E*).
> Format: 100% PG · Bahasa Indonesia · Kelas 10–12 SMA · Pembahasan analisis seluruh opsi.
>
> *Catatan opsi: default 4 opsi (A–D). Untuk mapel yang memerlukan 5 opsi (Astronomi, Kebumian, beberapa Fisika OSN), gunakan A–E sesuai pola soal asli KSN/IOAA/IESO/IPhO.

---

## Mata Pelajaran OSN/KSN SMA

Berdasarkan ketentuan resmi Pusat Prestasi Nasional (Puspresnas) / Balai Pengembangan Talenta Indonesia (BPTI), OSN/KSN SMA mempertandingkan **9 bidang utama**:

1. **Matematika (MTK)** — aljabar, teori bilangan, geometri, kombinatorika lanjut.
2. **Fisika (FIS)** — mekanika, termodinamika, gelombang, listrik-magnet, fisika modern.
3. **Kimia (KIM)** — kimia fisik, anorganik, organik, analitik.
4. **Biologi (BIO)** — sel-molekuler, genetika, anatomi-fisiologi, ekologi, etologi.
5. **Astronomi (AST)** — bola langit, mekanika benda langit, bintang, galaksi, instrumentasi.
6. **Kebumian (KEB)** — geologi, meteorologi, oseanografi, astronomi kebumian.
7. **Geografi (GEO)** — geografi fisik, geografi manusia, geografi regional, SIG.
8. **Ekonomi (EKO)** — mikroekonomi, makroekonomi, moneter, fiskal, internasional.
9. **Informatika/Komputer (INF)** — logika, algoritma, struktur data, kombinatorika komputasional.

## Konvensi Tingkat Kesulitan

| Kode | Nama | Komposisi |
|------|------|-----------|
| `campur` | Campuran | 50 Kab + 30 Prov + 20 Nas (default OSN) |
| `mudah` | Mudah | 100% Kabupaten (KSN-K, C2–C3, konseptual & terapan dasar) |
| `sedang` | Sedang | 100% Provinsi (KSN-P, C3–C4, multi-step 4–6 langkah) |
| `sulit` | Sulit | 100% Nasional (KSN, C4–C6, problem solving olimpiade) |
| `mudah-sedang` | Mudah & Sedang | 50 Kab + 50 Prov |
| `sedang-sulit` | Sedang & Sulit | 50 Prov + 50 Nas |

## Catatan Eksekusi

- Generation dilakukan **progresif 1 file per turn** (estimasi 60–80K tokens output per file karena tingkat SMA lebih kompleks).
- Status `[ ]` = belum di-generate, `[x]` = sudah selesai.
- Update centang di file ini setelah setiap file selesai.
- Urutan default: Kategori A → B → C → D → E → F → G → H → I → J → K → L → M → N → O → P → Q → R → S (komprehensif dulu per-mapel, per-materi belakangan).
- Tingkat kognitif SMA: Kab (C2–C3, terapan dasar), Prov (C3–C4, multi-step problem solving), Nas (C4–C6, olimpiade-tier dengan proof/derivasi/optimasi/sintesis lintas konsep).
- **Soal Olimpiade tier Nasional** mengacu pola: KSN-SMA, IMO-Shortlist (MTK), IPhO-style (FIS), IChO-style (KIM), IBO-style (BIO), IOAA (AST), IESO (KEB), iGeo (GEO), IEO (EKO), IOI/Bebras (INF). Adaptasi ke format 100% PG dengan opsi A–D (default) atau A–E sesuai pola mapel.
- **Catatan khusus mapel:**
  - **Informatika** dalam format PG: fokus pada *tracing algoritma*, *complexity analysis*, *graph reasoning*, *combinatorial counting* — bukan menulis kode penuh.
  - **Astronomi & Kebumian** sering pakai 5 opsi (A–E). Gunakan A–E pada tingkat Prov & Nas, A–D pada tingkat Kab agar konsisten dengan soal asli KSN/IOAA/IESO.
  - **Ekonomi** sering pakai kombinasi pernyataan (Soal Tipe IV: 1,2,3 benar / 1,3 benar / dll.) — adaptasikan tetap ke 4 opsi dengan kombinasi pernyataan jika perlu.
- User boleh redirect urutan kapan saja (misal: "fokus generate Astronomi dulu", atau "skip Informatika untuk sekarang").
