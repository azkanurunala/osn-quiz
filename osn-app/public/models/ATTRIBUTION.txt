Organ models in this folder are derived from the Human Reference Atlas /
HuBMAP Common Coordinate Framework 3D Reference Object Library
(https://humanatlas.io/3d-reference-library,
https://github.com/hubmapconsortium/ccf-3d-reference-object-library),
based on the NIH Visible Human male dataset, licensed under CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/).

Files were re-exported with Draco geometry compression via
@gltf-transform/cli (gltf-transform optimize --compress draco) to reduce
size for web delivery; geometry and materials are otherwise unmodified
from the source release.
