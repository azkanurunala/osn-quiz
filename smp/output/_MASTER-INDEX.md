# OSN SMP Prep — MASTER INDEX 198 File

> Roadmap lengkap paket pembinaan OSN/KSN SMP — **198 file × 100 soal PG = 19.800 soal**
>
> Setiap file: 100 soal Pilihan Ganda dengan pembahasan komprehensif (analisis A/B/C/D).
> Format: 100% PG · Bahasa Indonesia · Kelas 7–9 SMP · Pembahasan analisis 4 opsi.

---

## Mata Pelajaran OSN/KSN SMP

Berdasarkan ketentuan resmi Pusat Prestasi Nasional (Puspresnas) / Balai Pengembangan Talenta Indonesia (BPTI), OSN/KSN SMP mempertandingkan **3 bidang utama**:

1. **Matematika (MTK)** — aljabar, geometri, teori bilangan, kombinatorika.
2. **IPA** — terdiri dari **Fisika** dan **Biologi** (terintegrasi pada sesi tes).
3. **IPS** — Geografi, Sejarah, Ekonomi, Sosiologi/Antropologi.

---

## Konvensi Tingkat Kesulitan

| Kode | Nama | Komposisi |
|------|------|-----------|
| `campur` | Campuran | 50 Kab + 30 Prov + 20 Nas (default OSN) |
| `mudah` | Mudah | 100% Kabupaten (KSN-K, C2–C3, 1–3 langkah) |
| `sedang` | Sedang | 100% Provinsi (KSN-P, C3–C4, 4–6 langkah) |
| `sulit` | Sulit | 100% Nasional (KSN, C4–C5, problem solving) |
| `mudah-sedang` | Mudah & Sedang | 50 Kab + 50 Prov |
| `sedang-sulit` | Sedang & Sulit | 50 Prov + 50 Nas |
